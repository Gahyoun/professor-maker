# 분석 기록 자동 정리

보관 만료일은 회차 서버 등록일부터 UTC 달력 기준 5년입니다. 만료 즉시 분석 집계·내보내기에서 제외하며, 매일 03:00 Asia/Seoul의 Sites 클라우드 예약 작업이 물리 삭제합니다. 방문·게임 API 요청·사용자 컴퓨터 접속이 없어도 실행합니다. 일일 정리 사이의 삭제 지연은 정상 실행 시 최대 24시간입니다.

공개 게임은 `POST /api/maintenance/analytics-retention`에 `RETENTION_MAINTENANCE_KEY`를 요구합니다. 본문은 `{"consent":"anonymous-gameplay-five-years-v2"}`만 허용합니다. 이 정리 전용 키는 통계 열람·내보내기·가져오기·연구 목적 완료에 따른 전체 조기 삭제를 승인하지 않습니다. 만료 기록과 이전 정책 기록만 최대 500개 실행씩, 월별 행과 실행 행을 같은 D1 트랜잭션에서 삭제합니다. 반복 실행은 멱등이며 실제 삭제 결과로 건수를 집계합니다.

예약 실행 경로는 소유자 전용 Sites 접근 정책 뒤에 있습니다. 예약 작업은 매 실행 때 플랫폼의 서비스 접근을 새로 얻고 소유자 전용 경로에서 5분짜리 HMAC 정리 권한을 발급받아 공개 API를 직접 호출합니다. 정리 키는 서버에서 서명에만 사용하고 클라우드 작업에는 전달하지 않습니다. 임시 권한은 메모리에서만 사용하며 만료되면 새로 발급받습니다. 프롬프트·소스·브라우저에는 비밀키를 저장하지 않습니다. 정리 중 중간 실패가 발생하면 이미 완료한 배치는 유지하고 남은 배치를 다시 실행합니다. 정상 보관 기간 안에 있는 데이터나 90일 업로드 권한만 만료된 데이터는 폐기하지 않습니다.

응답은 실행 시각·기준 시각·삭제한 실행/월별 행 수·남은 만료 실행/월별 행 수·완료 여부만 포함합니다. 원시 분석 JSON·프로필·토큰·개별 실행 ID는 반환하거나 로그에 기록하지 않습니다. 실패는 최대 두 차례 재시도하고 계속 실패하면 운영자에게 알립니다. 일일 작업은 데이터만 정리하며 소스 수정·재배포·정상 데이터의 목적 완료 폐기를 수행하지 않습니다.

검증은 방문 없는 직접 정리 실행, 만료 경계, 한국판·북미판, 유효 보관 데이터 보존, 여러 배치, 중복 실행, 트랜잭션 실패 복구, 정리 권한과 관리자 권한 분리, 소유자 전용 경로의 비인증 차단을 포함합니다. 배포 후 플랫폼 서비스 접근을 사용한 실제 실행과 DB 읽기 확인으로 연결을 검증합니다.
