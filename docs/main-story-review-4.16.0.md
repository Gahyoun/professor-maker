## 유지한 이야기와 분기

- 트루 엔딩은 포닥 시절 국제우편 손편지와 소인 두 번 → 임용 결과를 기다리는 편지 → 교수만 아는 ‘사흘 전이 아니라 이틀 전이었다’ → 지난봄의 전화 → 학회에서 임용 후 첫 대면 순서를 유지한다.
- 강연은 마지막 슬라이드가 화면에 떠오름 → 종소리 → 감사 인사 → 박수 순서다. 마지막 대화는 `{name} 교수는 어떻게 생각해요?`로 동료의 의견을 묻는다.
- postdoc는 결과를 몇 달 전 메일로 들은 사실과 ‘추천서 한 장 때문은 아니었을 것이다’를 유지한다. 개인 연구과제·Research Professor·Junior Research Group Leader는 몇 해 뒤 경력의 변형이며 졸업 요건이 아니다. 직함과 계약·연구 역할을 명시하고 전임교원 임용과 혼동하지 않는다.
- 출연연 엔딩의 ‘함께 해 주시겠습니까?’, 빨간 펜을 찾다 멈추는 장면, ‘이번에는 제가 그쪽 연구실로 가겠습니다’를 유지한다. 창업의 마지막 질문도 wet에서는 ‘다음 실험은 무엇입니까?’, dry에서는 짧은 연구 질문이다.
- 편지의 회상·스탯 문장은 하나의 예산을 공유한다: close 최대 2개, reserved 최대 1개, distant 0개. 휴학·중단·운영 종료·미완·영상·제적은 0개다. 삽입은 요청 앞, 맺음말은 서명 앞이며 원문과 RNG를 수정하지 않는다.
- 고급 연구 경력의 newcomer/recovery 제외, dry 회상의 wet 어휘 제외, 이미 본 문장 ID보다 새 ID 우선, 보관한 ID 고정 규칙을 유지한다. 문장 후보를 모두 본 뒤의 반복까지 영구히 금지하지는 않는다.
- 퇴임식은 주요 8종 중 5종에서 해금되고 8종에서 마지막 장면이 열린다. 유튜버는 해금 개수에 포함하지 않으며, 이미 수집했다면 퇴임식의 카메라 장면에는 등장할 수 있다. 산 사진의 공개 동의는 유지한다.

추가로 고친 내용은 두 가지다. `unrelated` 편지의 도입에서 ‘새 분야에서 연구실에서 배운 것을 쓴다’는 설명이 다음 문단과 겹쳤고, dry 영문 치환은 ‘customer data instead of studies’라는 어색한 비교를 만들었다. 첫 문단을 새로운 업종에서 고객 데이터를 보는 현재 일 한 문장으로 줄이고, 다음 문단에 관찰·가설·수정의 배움을 남겼다. 가까운 관계의 교수 답장도 국문·영문에서 같은 대화를 담도록 맞췄다.

`audit-472-unrelated-072`의 ‘다음에’ 중복은 학생의 맺음말 한 번과 서명 뒤 교수의 답장 한 번을 합산한 검사 오류였다. 좋은 교수 답장을 삭제하지 않았다. `scripts/letter-prose-checks.mjs`가 인사에서 서명까지 이어지는 학생 편지를 페이지 경계와 관계없이 읽고, 서로 다른 편지는 각각 센다. 같은 학생 편지 안의 두 약속과 미완성 ‘교수님도’는 계속 실패하는 회귀를 추가했다. 대표 스크립트 생성기의 출처 설명도 1만 회 감사와 별도 실제 플레이를 함께 표시한다.
