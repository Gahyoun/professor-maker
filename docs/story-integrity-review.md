# 시나리오·이벤트·편지 정합성 검토 — 4.12.0

검토일: 2026-10-10. 5개 에이전트가 시간 흐름, 편지 조합, 사건과 선택의 인과, 전공·Wet/Dry, 학위·업무·병역 일정으로 나누어 독립적으로 검토했다. 중복 발견은 아래에서 하나로 묶었다. 발견 당시의 모순과 이번 수정의 결과를 구분해 기록한다.

발생 조건을 강화한 TA·원고 수정·방문 연구 사건이 이전 저장에서 이미 대기 중이었을 경우, 기존 회차를 초기화하지 않고 해당 사건을 건너뛰어 다음 정상 결정으로 이어 간다. 다른 잘못된 저장값을 허용하지 않는 회귀 검증도 추가했다.

## 핍진성이 유지되는 부분

- 트루는 포닥 시절 손편지 → 임용 결과 대기 → 지난봄 합격 전화 → 국제학회 첫 대면으로 이어진다. 사흘 전 부탁과 이틀 전 밤 추천서, 소인 두 번, 두 교수가 된 호칭을 유지한다.
- 포닥은 결과를 몇 달 전 메일로 들었다고 밝히며, 추천서 한 장이 임용 결과의 유일한 원인은 아니라고 쓴다.
- 진로는 능력·경험으로 판정하고 관계 장면은 라포로 구분한다. 기업 진출이나 학계 밖 생활 자체를 실패로 평가하지 않는다. 낮은 라포에서는 공개를 허락한 사진과 필요한 연락만 남긴다.
- 73개 전공과 진로 분야 매핑은 모두 대응한다. 건축은 설계·건물 성능, 수학은 정의·모형·증명, 컴퓨터는 코드·알고리즘, 화공은 공정·고분자로 연결된다.
- Wet의 생물 시료형 연구와 장치 시험형 연구를 구분한다. 연구실 장비도 생명·분석·계측·설계·계산 다섯 종류로 나눈다. Dry에서는 실험가운을 쓰지 않는다.
- 퇴임식은 여러 회차를 묶는 회상으로 설명한다. 주요 8종 중 5종부터 해금하고 전체 수집 시 마지막 장면이 추가된다. 유튜버 특수 엔딩은 해금 수에 포함하지 않는다.

## 사실 자료와 게임 규칙의 경계

전문연구요원 설명은 병무청의 [2026년 복무관리 매뉴얼 게시물](https://open.mma.go.kr/caisGGGS/board/boardView.do?gesipan_id=55&gsgeul_no=1518208&menu_id=m&pageIndex=1&pageUnit=10)을 대조했다. 검토 담당자는 현행 3주 표현과 군사교육소집 안내를 확인했다. 게임의 겨울방학 배치는 게임 일정이며 실제 소집 시기를 자유롭게 정할 수 있다는 안내가 아니다. 실제 편입 자격이나 선발을 게임 사건으로 보장하지 않으며, 최신 병무청·소속 대학 자료를 확인하라는 경고를 유지한다.

8년 진행, 고정 학회 주간, qual 기준, 학교 유형별 업무 감소량, 가상 IF·예산·과제 확률은 게임 규칙이다. 실제 대학·진로·가격의 대표 통계로 해석하지 않는다.

## 남겨 둔 개선 과제

1. 일부 일반 사건의 3·4번째 선택은 ‘계획 유지/보완 보고’라는 공통 문장이다. 인과 오류는 바로잡았지만, 사건별로 자원 예약·인계·안전 점검처럼 목적을 더 구체화하면 고민의 질이 높아진다.
2. 교수가 두 선택에서 같은 반응을 할 때가 있다. 선택별 비용과 상태 변화는 다르므로, 향후 후속 대사도 더 세분화할 수 있다.
3. 순수수학 경로는 그래프·오차막대보다 증명 초안·가정·반례를 더 많이 쓰면 좋다. 현 문장은 응용수학 연구에서는 가능한 장면이어서 확정 모순으로 처리하지 않았다.
4. 퇴임식의 오래된 장비 회고는 공통 장치다. 각 수집 회차의 장비·분야를 회고에 반영하면 연속성이 더 풍부해진다.

## 검증 방법과 한계

편지 담당자는 73개 분야의 허용 트랙, 엔딩, 라포 3구간, 받침 유무 이름으로 한국어 12,096개 조합을 검사했다. 플레이스홀더·조사 오류 및 Dry 후일담의 Wet 전용 보관 표현 누출은 발견하지 못했다. 영문 분야·보관 치환은 이번 패치에서 별도 전체 분야 회귀 검사했다.

발견한 사건과 학위 진행 오류는 유효한 가상 저장으로 재현하고 실제 월간 결정 큐를 거쳐 검증했다. 실제 플레이 발생 빈도는 별도의 [10,000회 worker 감사](ending-balance-audit.md)에서 확인한다. [대표 엔딩 스크립트](ending-script-examples.md)와 [실제 종료 기록 검토 화면](../dist/ending-review.html#retirement)도 함께 제공한다. 문학적 완성도 전체나 실제 제도의 모든 예외까지 검증했다는 뜻은 아니다.
