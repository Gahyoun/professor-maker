# 엔딩 스크립트 대표 시나리오

2026-10-10 · 게임 4.15.1 · 한국어

이 문서는 실제 게임의 `getEndingPages`·`researchText`·`retirementScenes`로 생성한 전체 장면입니다. 관측한 엔딩은 백엔드 시뮬레이션(10,000회)의 종료 상태와 이름·분야·파라미터·이벤트 기록을 그대로 사용했습니다. 관측하지 못한 엔딩 장면은 **합성 예시**로 명확히 구분하며, 그 설정이 실제 플레이로 도달했다는 뜻은 아닙니다. 엔딩 비율은 [별도 통계 보고서](ending-balance-audit.md)를 참고하세요.

편지 안의 성격·능력·분야·연락 거리·실제로 기록된 선택에 관한 문장도 현재 생성 결과 그대로 포함합니다. 본문에 별도 편지가 없는 장면에 새 편지를 덧붙이지 않았습니다.

## 판정 읽는 법

박사 진로는 트루 → 포닥 → 교내 연구원 순으로 먼저 검사한 뒤, 나머지 유효한 진로 중 점수가 가장 큰 것을 선택합니다. 동점 순서는 영상 → 스타트업 → 기업 연구개발 → 정출연 → 새 분야입니다. 아래의 최소값 하나만 넘었다고 해당 엔딩이 보장되는 것은 아닙니다. 박사학위요건은 전공별이며, 자격시험 통과와 연구수행 50 이상도 필요합니다.

학습·연구수행·어학·의사소통·라포 등의 기준은 원래 숨은 수치의 **0–100 정규화 점수**입니다. 라포에 따른 편지의 거리 구간은 가까움 70 이상, 중간 40 이상·70 미만, 거리 유지 40 미만입니다. 트루의 임용 기준인 라포 80는 그보다 엄격합니다.

공통 박사학위요건과 자격시험 통과도 검사합니다. 수상은 추가 성취로 기록하며 임용 후보의 필수 관문은 아닙니다. 임용 후보 조건에 라포를 제외하고 모두 해당하면, 라포 80 이상은 트루, 40 이상·80 미만은 포닥 후일담이 됩니다.

외부 진학을 권해도 내부에 남을 확률은 `clamp(0.1 + 라포×0.006, 0.1, 0.7)`입니다. 내부 진학을 권했을 때 학생의 거절 확률은 라포 60 이상이면 0, 그 미만이면 `clamp((60−라포)×0.012 + (의욕<50 ? 0.08 : 0), 0, 0.5)`입니다.
