## 제작자 결정과 처리 (10/11)

1. **학위논문 심사 시점** (A-05) → 직전 학기로 이동. 석사 9·11·12월(보완 4·5·6월), 박사 8년차 9·11·12월. 3월 학위 결정은 12월 판정을 따른다. 판정이 두 달 앞당겨져 마지막 1–2월에 요건을 채우던 회차는 졸업하지 못한다(전략 6종 × 100시드 비교: 학위요건 미충족 7 → 10판, 구직 13 → 31판, 출연연 98 → 79판).
2. **전문연구요원 군사교육소집** (A-04) → 박사 단계로 제한. 석사 경로는 박사 진학 뒤, 통합과정은 5학기부터. 석사 단계 상담에서는 소집 일정을 고를 수 없고 안내 문장을 덧붙인다.
3. **통합과정 인건비** (A-23) → 첫 4학기는 석사 기준, 이후 박사 기준.
4. **KCI 표기** (A-18) → `국내 등재지 · 가상 학술지`. 내부 id `kci`는 저장 호환을 위해 유지.

## 화면 개편: 대학 학사정보시스템 스타일

`dist/academic-portal.css`를 마지막에 불러와 기존 스타일 위에 덮는다. 기존 파일의 `!important` 층을 건드리지 않기 위해서다.

- 상단: 남색 유틸리티 바(접속자 표시 `○○ 교수 · 교원 접속`), 로고 옆 시스템명 `교수 업무 포털`, 메뉴 아래 2px 남색 구분선.
- 위치 표시줄: 홈 아이콘 + `홈 › 학생 지도`, 오른쪽에 자동 저장 상태 배지.
- 페이지 제목: 왼쪽 파란 막대 + 아래 2px 남색 선. 인쇄는 테두리 버튼.
- 패널: 모서리 3px, 위쪽 2px 남색 선, 그림자 제거. 섹션 제목 앞 네모 표지.
- 주별 지도계획: 데이터 그리드처럼 주차 칸을 회색 머리칸으로, 행마다 구분선. 학회·시험 주간은 머리칸 색으로 표시.
- 공지: 메인스토리 목표는 공지 상자, 저장 경고는 `※` 안내 상자, 빈 목록은 "조회된 내용 없음" 형식.
- 가독성: 8–10px였던 주차·제안·라벨·설명 글자를 11–14px로 올림. 모바일 방 라벨 최소 11px.
- 메뉴명 통일: `연구실/기록/메일` → `학생 지도/연구 기록/메일함` (페이지 제목·위치 표시와 동일).
