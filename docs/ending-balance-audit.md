# 엔딩 밸런스 감사 · v4.15.3

검사일: 2026-10-11 (한국 시간). 실제 브라우저용 simulation-worker의 월 진행·결정 핸들러를 Node worker_threads에서 호출해 **10,000회** 실행했습니다. 소요시간 145.2초.

새 회차에서 시작하며 능력·연구비·논문·수상 수치를 주입하지 않았습니다. 12개 지정 전략을 거의 동일한 횟수로 섞고, 73개 분야·가능한 wet/dry 방식·3개 학교 유형을 순환했습니다. 각 전략 안에서도 성별을 교차했습니다. 허용된 일정·예산·업무 배분·진학·이벤트 선택만 지정했습니다. 선집행은 게임 내 한도 안에서 활성화했습니다. 3월·9월 공고에서 자금 필요 또는 후속 마감을 확인해 신청하고, 잔액이 적으면 예산·계상률을 낮추며 이벤트에서 감당할 수 있는 대안을 선택합니다.

**전체 비율은 이 전략 혼합의 결과이며 실제 플레이어 승률이나 현실의 진로 확률이 아닙니다.** 전략별 비율을 함께 봐야 합니다. 동일한 시드·정책이므로 재실행해도 결과가 바뀌지 않습니다.

임용 준비 faculty 전략의 트루 도달: **9 / 834 (1.08%)**. 선도 논문과 추천 경험, 교육·어학, 교수 업무를 의도적으로 준비한 전략에서 실제 도달이 확인됐습니다. 현행 조정값으로 실행했으며 상태를 주입하지 않았습니다. 이 수치는 2~3회 재도전의 성공을 보장하지 않으며, 이전 엔딩 수집이 확률을 올리는 메타 보너스도 사용하지 않았습니다.

`formal-faculty`는 같은 준비를 하되 마지막 8개월에 강한 지적을 반복하는 비교 전략입니다. 추천서 경력 조건을 갖춘 상태에서도 라포가 다르면 포닥 분기로 갈리는지 확인합니다. 현실의 임용 결과를 추천서 한 장으로 설명한다는 뜻은 아닙니다.

`communication`은 학위 연구요건을 채운 뒤 전 주를 어학·발표에 배정하며 회복 시간을 확보하지 않는 스트레스 검사입니다. 이 전략의 휴학이 많다는 사실을 영상 엔딩의 희귀성만으로 해석하지 않습니다. `industry`와 `venture`는 RA, `graduate`는 학사 졸업, `masters`는 석사 졸업을 선택합니다. `new-field`와 `job-search`는 최소 학위 연구요건 이후 기존 연구를 더 쌓는 대신 다른 활동으로 이동합니다. `independent`는 자율 일정 중심, `low-contact`는 추가 대화 없이 통상 업무를 반복합니다. `guided`는 연구·분석과 회복을 함께 배정합니다.
