# 엔딩 밸런스 감사 · v4.11.0

검사일: 2026-10-10. 총 10,000회, 12개 정책, 73개 분야와 가능한 연구실 방식 및 3개 학교 유형을 순환했습니다. 난수 시드는 `7919 × (회차 + 1)`입니다. 실제 브라우저용 simulation-worker의 월 진행·결정 핸들러를 Node worker_threads에서 호출합니다. 소요시간 약 156초.

새 회차의 초기 상태에서 시작하고, 능력·연구비·수상·논문을 주입하지 않았습니다. 출판 목표, 선택 가능한 주간 일정, 업무 크레딧·예산·선집행, 이벤트 응답과 진학 선택만 바꿨습니다. 이 표는 전략을 지정한 자동 플레이 결과이며 실제 플레이어의 엔딩 확률이나 현실의 진로 확률이 아닙니다.

임용 준비 `faculty` 전략은 331 / 834 (39.69%)로 트루 엔딩에 도달했습니다. 선도 논문, 추천서와 교육 경험을 의도적으로 준비한 전략입니다. 기존의 14개 수치 조건을 다시 낮추지 않아도 이 전략에서는 대략 2~3회 시도 범위에 해당합니다. 전체의 트루 비율은 임용 준비 전략을 얼마나 섞느냐에 따라 달라집니다.

`formal-faculty`는 같은 임용 준비를 하되 마지막 8개월에 강한 지적을 반복하는 비교 전략입니다. 라포가 다른 추천서 분기로 회수되는 포닥 후일담을 관측했습니다. 추천서는 현실의 임용 결과를 단독으로 설명하지 않습니다.

학계 밖 진로는 낮은 라포나 낮은 업무 능력을 필수 조건으로 두지 않았습니다. 해당 경로의 편지와 연락 방식은 별도의 라포 구간으로 조합합니다.
