# 분야별 투고 모델

73개 전공을 18개 분야군으로 연결한다. 각 분야의 기초·전문·선도 저널에 서로 다른 가상 IF를 부여한다. 수치는 게임 설계값이며 실재 학술지의 JCR 통계나 분야 평균을 추정한 값이 아니다. 모든 이름은 가상의 학술지다.

투고에 필요한 연구량·심사 난도·심사 기간은 해당 분야 안의 저널 수준으로 정한다. 인용 성장의 가시성 가중치도 기초 0.027, 전문 0.063, 선도 0.12로 통일한다. 따라서 수학의 선도 저널을 선택했다고 의학보다 불리하게 계산하지 않는다. 이미 저장된 논문은 당시 기록한 IF를 유지한다.

KCI 선택지는 국내 현장·정책·실무 연구를 다루는 응용 전공에 제공한다. 이는 이 게임의 선택 범위이며, 다른 분야에 KCI 학술지가 없다는 뜻이 아니다. 국내 전문 학술지에는 IF를 부여하지 않는다. 심사는 2개월, 연구량 배율은 1.05, 국제 기초 저널 대비 게재 확률 보정은 -0.03이며 인용 가시성 가중치는 0.035다. 모두 게임 설계값이다. 게재 논문·완료 연구·졸업 요건에 포함하고, 국제 선도 저널 실적에는 포함하지 않는다.

설계 참고: [Clarivate JCR 안내](https://clarivate.libguides.com/jcr/)의 분야 내 비교와 [KCI 학술지 검색](https://www.kci.go.kr/kciportal/po/search/poSereSear.kci)의 국내 학술지 경로를 참고했다. KCI 등재 상태와 JCR IF는 동일한 지표가 아니다.
