# 4.18.0 운영·경제·휴식·첫 플레이 검수

## 게임 규칙

새 게임의 기본 선택은 신임교수(쉬움)이다. 현실(보통)은 정착지원이 없는 기본 난도다. 저장한 난이도는 유지하며 이전 저장은 현실로 해석한다.

| 항목 | 신임교수(쉬움) | 현실(보통) |
| --- | --- | --- |
| 시드별 초기 총 연구비 | 최소 8,000만원, 상한 2억원 | 3,000만원–2억원 |
| 첫 24개월 정착지원 | 필수 부족액만 월 최대 300만원·총 3,000만원 | 없음 |
| 성장·성과 보상 | 공통 규칙 | 공통 규칙 |
| 앞으로의 연구비 지급 | 기존 규칙에서 15% 증액 | 동일 |
| 자금 부족 시 월 확정 | 차액 자동 차입 | 동일 |

지원과 폐쇄 기준은 가상의 게임 규칙이다. 정착지원은 필수 인건비와 분야별 기본 유지비만 보전하며 선택 지원·학회 경비는 별도다. 신규·갱신 계약에는 완만한 분야 계수를 적용한다. 기존 계약의 과거 금액·잔액·이력은 유지하고 미래 입금에만 공통 15% 인상을 적용한다. [분야별 근거와 설계값](research-finance-4.18.0.md)을 따로 명시했다.

## 진행과 종료

현금이나 인건비 풀이 부족해도 유효한 월 계획은 확정할 수 있다. 차액은 자동으로 학과 차입에 기록하며 월 이자 0.25%와 작은 학교행정 부담을 반영한다. 기존 저장의 차입금이 옛 상한을 넘어도 진행한다. 학생인건비 풀은 인건비만 지급하고 운영비·차입 상환에 쓰지 않는다. 과제 입금은 차입을 상환할 수 있으며 총 입금과 상환액을 구분해 알린다. 월 전 휴식 응답은 비용·이자·입금·달력을 진행하지 않는다.

매달 새 차입이 발생하고 상환 뒤 미상환액이 1천만원 초과인 상태가 3개월 연속이면 운영 종료다. 큰 차입 첫 달에 학과장 면담으로 남은 두 달을 알린다. 오래된 차입금이 남아 있다는 이유만으로 종료 기록을 늘리지 않는다. 직접 운영 보류를 선택한 경우에는 실제 보류 3개월을 별도 원인으로 기록한다. 차입과 보류 사이에 모드가 바뀌면 새 회복 기간을 계산한다.

교수 업무가 15 이하이면 조정을 요청하고, 특정 업무가 처음 0이 된 달에는 회복할 두 달을 알린다. 네 업무의 연속 기록은 각각 계산한다. 회복하면 해당 기록을 초기화하며 같은 달의 후속 선택은 월수를 다시 증가시키지 않는다. 종료 화면·편지·저장 기록에 구체적인 원인을 남긴다.

## 휴식·학회

일반 휴식 요청은 스트레스 80 이상이면서 체력 30 이하 또는 정신력 20 이하인 경우, 또는 체력 18 이하·정신력 12 이하의 심한 피로에서 나온다. 응답 뒤 3개월 동안 일반 재요청을 막고 실제 임계 상태는 예외로 둔다. 요청은 1–2주이며 허락은 고정 일정 외에 회복 시간을 확보하고 라포를 한 번만 높인다. 거절은 기존 연구 일정을 유지하며 스트레스를 한 번만 높인다. 시험·심사·선택한 학회 일정은 보호한다. 저장·재로드·계획 복원으로 응답 효과를 반복하지 않는다.

평소 자율 시간의 휴식 가중치를 낮추고 일반 미수행을 휴식으로 바꾸던 처리를 제거했다. 실제 한계에서는 원인과 경고를 붙여 회복한다. 해외 연구년 중 교수 단독·교수 동반 국내학회 참석은 제한하고 학생 단독·불참은 허용한다. 기존 예정 참석은 학생 또는 불참으로 조정해 한 번 기록하며 귀국 후 선택을 복원한다.

## 첫 플레이와 시각 확인

온보딩의 버전별 플로팅 안내는 변경사항을 알려주고 닫기·다시보기를 지원한다. 입학면접은 후보 3명의 성적·관심 분야·면접 인상만 보여준다. 숨은 성실도·내성은 노출하지 않고 후보와 설정은 새로고침에도 유지한다. 선택한 학생의 생성 난수·능력을 다시 뽑지 않는다. 공유 코드로 후보를 재현한다. 기존 저장의 학생은 변경하지 않는다. 진행 중과 면접 중의 새 학생 시작은 버튼과 이벤트 처리 양쪽에서 막고, 현재 지도가 종료된 뒤 새 면접을 연다.

첫 면담 뒤 목표·콘텐츠→메뉴→주간 계획→교수 업무→예산→연구비 신청→월 확정→수행 보고의 8단계 화면 안내가 나온다. 안내 저장은 게임 저장과 분리하고 건너뛰기·뒤로·중간 재로드·재시작을 지원한다. 결정·월 연출 중에는 숨긴다. 모바일에서 카드와 진행 버튼이 겹치지 않도록 여백을 계산한다.

곱슬 긴머리·Wet 포니테일·땋아올린 번의 뒷목 가림을 실제 연구실에서 확인했다. 접이식 침대 전체와 모든 지지 다리를 바닥 안쪽에 배치하고 전체 면적 기준으로 깊이를 정렬했다. 320·390·1360px에서 안내와 그림의 겹침·가로 넘침을 검사했다. 물리학 트루엔딩 전용 독자는 실제 이야기 10장면을 재사용하고 일반 메뉴에 연결하지 않으며 게임 저장 API를 호출하지 않는다.

## 확인한 검증

전체 단위 검사 435개가 통과했다. 신규 입학면접·숨은 정보 보존·저장 검증, 요청 쿨다운·한계 예외·심사 일정, 분야별 지출·계약 금액, 자동 차입·입금 중복 방지, 오프라인 필수 모듈을 포함한다. 실제 브라우저 검수는 별도로 수행했다. 배포 Worker의 메인 화면과 신규 모듈·트루엔딩 전용 경로가 모두 200 응답이며 배포 CSP 아래에서 동작하는지 확인했다.

## 실제 Worker 정책 실행

[재현 스크립트](../scripts/lab-closure-audit.mjs), [두 방식·두 난이도 160회 결과](lab-closure-audit-4.18.0.json), [6개 분야 120회 결과](discipline-policy-audit-4.18.0.json)에 엔진·경제·정책 소스 해시를 기록했다. 허용된 계획·연구비 공모·면담 선택만 사용했고 역량·돈·논문을 주입하지 않았다. 현금 부족을 수동 구조나 강제 보류로 우회하지 않았다.

| 160회 짝지은 정책 | 실행 | 오류 | 연구비에 따른 운영 종료 | 평균 논문 수 |
| --- | ---: | ---: | ---: | ---: |
| 현실 | 80 | 0 | 1 | 3.0375 |
| 신임교수 | 80 | 0 | 1 | 3.0250 |

6개 대표 분야(수학·컴퓨터·환경·건축·재료·간호)의 별도 120회에서 오류 0, 연구비에 따른 운영 종료 2회, 평균 논문 3.575편이었다. 위 정책은 공모를 계획적으로 신청해 정착지원은 사용하지 않았다. 초기 지원의 월·총 한도와 선택 지출 제외는 별도 부족액 경계 검사로 검증했다.

이 결과는 실제 플레이어 승률이나 현실 진로 확률이 아니다. 두 방식 비교는 서로 다른 대표 전공이며 인과 효과로 해석하지 않는다. 일반 요청 임계값·쿨다운 보강 전 같은 160회 정책의 요청 2,003회는 최종 정책에서 1,945회로 줄었으나 분야 경제 변경도 함께 포함돼 휴식 규칙만의 효과로 해석하지 않는다.
