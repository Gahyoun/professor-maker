# 엔딩과 편지의 분리

진로 적합도와 관계 묘사는 별도로 판정합니다. 기업 연구개발, 새로운 분야의 기업 진로는 라포를 진로 점수로 사용하지 않습니다. 해당 장면과 편지의 연락 방식은 종료 시점 라포 구간으로 결정합니다. 한국어 이름·조사는 저장된 학생 이름과 받침으로 처리하고, 연구실 방식과 73개 분야 매핑을 사용합니다.

## 시나리오 시간순서

트루: 포닥 중 추천서 요청 → 마감 이틀 전 밤 세 차례 수정·발송 → 임용 결과 전 국제우편 손편지(두 소인, junior leader) → 다음 봄 합격 전화 → 학회 초청 강연 → 임용 뒤 첫 대면과 두 동료의 대화.

포닥: 이전 지원 결과는 이미 메일로 전달 → 저널 표지 알림 → 그 메일과 형식적인 추천서 회상 → 일반 구두 발표 → 다음 부탁을 먼저 받아들이겠다는 교수의 말. 추천서 한 장이 결과의 단일 원인이라는 서술은 피합니다.

## 편지 조합

정해진 주요 장면 사이에서 실제 이벤트 기억, 성격, 회복 상태와 자율성, 강점 분야, 전공의 작업과 연구실 방식에 맞는 구문을 조합합니다. 능력별 서로 다른 원척도는 0–100으로 정규화한 뒤 비교합니다. 이 조합은 난수를 소비하지 않고 종료 기록만 읽으므로 저장한 편지는 다시 읽어도 동일합니다.

높은 라포는 다음 만남과 이야기를 자연스럽게 이어 갑니다. 중간 라포는 진로별 구체적인 근황이나 필요한 연락을 남깁니다. 낮은 라포에는 공통 감정적 맺음말을 붙이지 않고 필요한 인계와 학생의 연락 경계를 존중합니다. 외부 진학·학사 졸업·영상 엔딩에는 중간 라포의 공통 어색함 문장을 사용하지 않습니다. 영상 엔딩에만 별도의 개그 구문을 붙입니다.

## 판정 기준

모든 수치는 게임 기준이며 실제 임용 확률이나 사람의 평가가 아닙니다.

- 트루: 박사 학위요건·퀄 통과, 학습78 / 연구82 / 어학70 / 의사소통60 / 자율78 / 교육65 / 라포80 / 정신력60 / 예의60 / 의욕65. 논문3 / 학술발표3 / 추천서3, 교수 업무 각40, 선도 논문1 / h-index2. 무작위 수상은 필수가 아닙니다. 전공별 학위요건에서 요구하는 발표 횟수도 별도로 충족해야 합니다.
- 포닥 추천서 분기: 라포 외 임용 준비 기준을 모두 충족하고 라포40 이상80 미만.
- 정부출연연: 연구수행70 / 학습65 / 자율60과 논문4편 또는 논문2편·선도 논문1편. 최소 학위 연구만 마치고 다른 진로를 준비한 경로를 논문 수만으로 흡수하지 않습니다.
- 교내 연구원: 학위요건 충족, 높은 라포와 연구실 운영 여건, 신중함·안정 선호 기질65 이상. 낮은 정신력은 조건이 아닙니다.
- 영상 특수 경로: 어학·의사소통90 이상이면 적합도80. 기존 과학소통 경험 경로도 유지합니다. 다른 진로와 적합도를 비교하므로 90 도달이 항상 영상 엔딩을 강제하지는 않습니다.
- 퇴임식: 유튜버를 제외한 주요8종 중5종이면 기본 장면,8종 모두면 마지막 장면. 유튜버를 추가로 보았다면 게스트 장면만 추가합니다.

연구 일정 1주에서 얻는 프로젝트 진행량은 이전의 절반입니다. 학습·연구 능력의 성장과 재현성 판정은 유지하며, 논문 수를 직접 삭감하지 않습니다. 한 연구의 검증·분석·원고 작성에 더 오래 투자하게 합니다.

시뮬레이션 결과와 전략별 제한은 [엔딩 밸런스 감사](ending-balance-audit.md)에 기록합니다.
