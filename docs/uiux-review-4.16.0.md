# 계획·상담 UI/UX 검토 — 4.16.0

이번 검토는 실제 입력, 키보드 포커스, 화면 크기와 시뮬레이션의 집행 조건을 함께 확인했다.

- 학생이 요청한 회복 시간을 계획 위에 표시한다. 버튼을 누르면 제안된 회복 주간만 반영하며 다른 합의, 고정 시험·학회 일정은 유지한다. 이미 반영한 회복을 수동으로 해제해도 버튼이 다시 나타난다. 월은 진행하지 않는다.
- 진행을 막는 이유를 운영비 부족, 인건비를 포함한 총액 부족, 업무 한도, 공고 시기, 3책5공 한도로 구분한다. 인건비 풀을 운영비로 사용할 수 없다는 점을 설명하고 해당 조정 항목으로 포커스를 옮긴다. 닫힌 과제 패널도 먼저 연다.
- 크레딧 블록, 참석·저널·선집행 조정 후 화면이 다시 그려져도 조작한 항목에 포커스를 유지한다. 상담 선택 뒤에는 다음 질문이나 계획 제목으로 옮긴다.
- 크레딧 버튼은 44×44px 이상으로 조작할 수 있다. 모바일에서는 연구실 그림을 계획 중 일반 흐름에 두어 입력을 가리지 않는다. 주간 재생 때의 고정 장면, 조작 잠금과 건너뛰기는 유지한다. 데스크톱의 고정 연구실도 유지한다.
- 새 안내와 이동은 모션 줄이기 설정을 따른다. 기존 기기 저장과 수집한 편지를 초기화하지 않는다.
- 연구실 안내 문구는 그림 위의 별도 행을 사용해 창문·가구와 겹치지 않는다. 320·390·516·900·1360px에서 카드·문구의 부모 영역 경계와 그림의 비겹침을 확인했다. 좁은 화면의 대기 장면에서는 불필요한 고정용 덮개도 제거했다.

독립 Chromium context에서 320·390·1360px의 가로 넘침, 터치 영역, 키보드 조작, 휴식 제안의 표시·해제·복원, 운영/인건비 풀 구분, 닫힌 공고·PI 한도와 역할 변경, 실제 Worker 한 달 진행을 검사했다. 캠퍼스 테마·주간 재생·계상률 변경·상담의 기존 UI 검사도 통과했다. 콘솔 pageerror는 0개다.

KO/EN × wet/dry × 10개 월 × 국내 참석 4유형의 160개 비용 경계는 실제 `simulateMonth` 집행 허용 여부와 대조했다. 테스트에 쓰는 상태는 사용자의 저장과 분리된 입력 fixture이며 승률 표본으로 집계하지 않는다.

재현: `tests/advising-plan.test.mjs`, `tests/advising-ui-smoke.mjs`, `tests/campus-ui-smoke.mjs`, `tests/monthly-ui-smoke.mjs`. 브라우저 검사는 `GAME_URL`로 별도 로컬 서버를 지정한다.

## CV의 연구실 장면과 저장

새 CV에는 마지막 수행월의 전공·wet/dry 방식·실제 자재량과 계절을 담은 연구실 그림을 고정한다. 학생 도트를 생략한 자체완결 SVG를 압축해 이미지로 표시하며, 기존 v1–v3 CV에 장면을 소급 생성하지 않는다. 전공별 장비와 계절 원근 검수는 [연구실 검수](lab-visual-review-4.16.0.md)를 참조한다.

새 그림은 모바일·데스크톱, 독립 HTML과 PDF에 함께 나타난다. 5종 CV의 첫 A4 요약 구조는 유지하고 연구실 그림은 전체 논문 목록과 같은 부록에 둔다. 새 모듈도 서비스 워커의 오프라인 설치 목록에 포함한다.

저장 파일의 UTF-8 상한은 4.5MB다. 보관함은 40개를 유지한다. UTF-8 파일 크기와 기기 저장 용량은 다르므로 실제 저장 성공을 확인한 뒤 불러오기 성공을 안내한다. 저장에 실패하면 이전 진행·보관함·회상 ID·탭과 변경 전 5개 기기 저장 키를 복원한다. 스크립트·외부 이미지·이벤트 속성·잘못된 XML을 포함한 수입 SVG는 거절한다.

재현: `tests/cv-lab-scene.test.mjs`, `tests/cv-lab-scene-ui-smoke.mjs`, `tests/offline-module-cache.test.mjs`. 압축 전후 그림은 브라우저의 동일 canvas 래스터로 비교한다. 용량 검수에는 별도 감사 corpus의 가장 풍부한 실제 CV와 가장 큰 연구실 그림을 결합한 40개 합성 보관함을 사용하며, 이 fixture를 승률 감사에 포함하지 않는다.

최종 Chromium 검수는 1,408개 전공·모드·시드·계절·풍부한 자재·수상 조합을 탐색했다. 최대 그림 URI는 43,939자였고, 가장 풍부한 실제 종료 CV와 결합한 40개 보관함을 실제로 저장·재실행·내보내기·다시 불러왔다. 501개 이력의 현재 저장과 이전 v3 키를 함께 유지한 총 기기 저장량은 UTF-16 5,038,548바이트, 예쁘게 들여쓴 JSON 내보내기는 UTF-8 2,851,881바이트였다. 운영체제의 저장 설정에 따라 실제 한도는 달라질 수 있으므로 실제 저장 실패도 별도로 검증했다.

두 차례의 보관함 저장에 `QuotaExceededError`를 주입해 원래 게임·보관함·회상 ID·탭과 5개 저장 키가 모두 복원되고 성공 안내가 나오지 않는 것을 확인했다. 320/1360px, HTML 독립 다운로드, PDF 5종, 압축 전후 canvas와 유효하지 않은 SVG 수입 거절도 통과했다. A4 content width 703px에서 요약 높이를 확인하고 실제 PDF의 첫 두 페이지 PNG를 직접 검수했다. 원게임 RNG와 숫자 감사 결과는 변경하지 않았다.

최종 출력 기록: 프로젝트 outputs의 `pm4160-cv-lab-scene-root-qa/report.json`, `cv-*.pdf`, 첫 두 페이지 PNG. 전체 단위 테스트는 352/352개 통과했다.

## 4.16.1 화면 재검토

첫 주의 달력 표식도 연구실 라벨을 가리지 않도록 주간 헤더의 별도 행으로 옮겼다. 320·390·516·1360px의 실제 월 재생에서 달력 → 헤더 끝 → 라벨 → 그림 순서와 가로 넘침 0을 독립 검증했다. 모션 줄이기의 표식·재생 애니메이션 생략과 키보드 건너뛰기·종료 후 입력 복원도 통과했다. 전체 단위 테스트 352개가 통과했으며 화면은 outputs의 `pm4161-scene-review/`에 보관한다.

## 4.16.2 스크롤 고정 해제

사용자의 요청에 따라 연구실 그림은 모든 화면 크기와 주간 재생에서 일반 페이지 흐름으로 바꿨다. 고정용 덮개도 숨긴다. 320·390·1360px의 대기·재생 6개 사례에서 페이지가 100px 내려갈 때 카드도 정확히 100px 올라가며 화면에 고정되지 않는 것을 독립 검증했다. 날짜·안내·그림의 분리, 가로 넘침 0, 건너뛰기와 월 진행·입력 복원도 통과했다. 계획·월 재생·키보드·모션 줄이기 UI 검사와 오프라인 모듈 검사도 통과했다. 측정값과 화면은 outputs의 `pm4162-lab-flow-independent/`에 보관한다.

## 4.17.2 긴머리와 의자 레이어

모니터를 향해 앉은 학생의 긴머리를 의자 등받이가 덮어 짧게 보이던 원인을 수정했다. 합성에서 머리로 판정된 픽셀만 등받이 다음·가까운 팔걸이 이전에 그린다. dry 긴머리·곱슬머리와 wet 포니테일에 적용하고, 번·단발·짧은 머리는 적용하지 않는다.

머리·의상·의자·CV·오프라인 관련 기존 검사 44개가 통과했다. 독립 검수에서 정면·모니터·TA·실험·휴식의 초상화 720개가 원본과 동일했고, 96개 실제 연구실 조합의 변경 픽셀은 머리 영역 안에만 있었다. 번 32개는 장면과 PNG 모두 동일하다. 모바일 360px 12개와 390px 화면의 겹침·넘침을 확인했다. 비교 화면과 결과는 outputs의 `pm4172-long-hair-*.png`, `pm4172-long-hair-independent.json`에 보관한다.
