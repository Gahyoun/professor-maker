# Versioned student names

New Korean intake drafts explicitly use naming version 2. The curated Korean pool contains 107 masculine given names, 113 feminine given names, and 59 surnames. These are whole authored names, not generated syllable combinations. Surname weights are game choices rather than population estimates. Names are cosmetic and do not consume simulation randomness or classify personality.

Version 1 remains available with its original ten-name pools and draws. Drafts without a naming version use version 1, and old `PM-` share codes preserve those exact applicants. New `PM2-` codes pin version 2. Saved student names, CV titles and archive images are never regenerated.

The three version-2 candidates receive distinct names. A collision changes only the name variant, preserving candidate seed, attributes, GPA and interview impression. Admission uses the displayed name, including any cosmetic collision correction.

New English intake drafts use naming version 3 and `PM3-` codes, with 96 authored multicultural preferred full names in each display-gender pool. Version-3 candidates also receive distinct names without changing the underlying students. Existing English `PM-` and `PM2-` codes retain their original name pools and applicants; version-2 duplicate-name resolution remains unchanged. `PM3-` codes are restricted to the English edition. Names do not establish race, nationality, citizenship, or ability; see [U.S. student representation](us-student-representation.md) for the independent cosmetic and educational-background design.
