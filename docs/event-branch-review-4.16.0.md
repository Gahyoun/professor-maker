# 분기점·이벤트 재검수 — 4.16.0

검수 기준 버전은 4.15.5다. 62개 이벤트와 학위·월말 큐, 73개 전공의 제공 연구실 모드, 저장 불러오기를 함께 살폈다. 아래 수치는 게임의 검사 사례이며 실제 대학 제도나 사건 발생률에 대한 추정이 아니다.

대사 수정은 이벤트의 수치 효과를 변경하지 않는다. 가중치와 조건 수정은 앞으로 등장할 사건의 선택을 바꿀 수 있다.

## 사용되지 않던 희귀 가중치

`one-student-lab.weight=.3`, `military-hidden.weight=.5`가 있었지만 실제 선택은 둘 다 기본 가중치 1을 썼다. 상담은 별도의 균등 인덱스 선택이어서 가중 선택 함수를 전혀 사용하지 않았다.

선언 가중치를 기존 사교성·기관·나이 계수에 곱한다. 상담에서는 기존 seed 해시를 0–1 추첨값으로 사용하므로 게임 RNG를 추가로 소비하지 않는다. 일반 무작위 이벤트는 기존과 같은 1회 RNG 추첨을 유지한다.

재현 검사에서 병역 계획이 남은 남학생·남교수 300개 seed의 같은 상담 기회를 비교했다. 일반 상담 5종은 각각 52–57회, 병역 상담은 26회 등장했다. 이 사례는 `.5`가 실제 선택에 작동하는지를 확인하는 고정 fixture이며 전체 플레이의 병역 상담 빈도를 뜻하지 않는다.

## 저장과 이전 결정

잘못된 시기에 이미 대기 중인 채점·통과 후 퀄 상담은 불러올 때 해당 결정만 정리한다. 학생 능력·진로 성과·연구비·seed·진행월을 초기화하지 않는다. 아직 유효한 대기 사건은 그대로 유지한다. 원본 저장 객체는 변경하지 않으며 두 번째 불러오기에서는 같은 이관 기록을 다시 추가하지 않는다.

## 기존 구현이 지키는 분기

- 학부 TA 불가, 대학원 진학 후 수업보조 허용.
- 석사·통합과정 구분, 석사 요건 미충족 시 1회 6개월 연장, 통합과정 별도 석사심사 생략.
- 자격시험 전공과목 준비, 첫 미통과 뒤 재응시 준비, 두 번째 미통과 시 제적. 통합과정 중단과 제적은 서로 다른 기록.
- 연구년 마지막 달까지 교육·행정 자동 감소 면제. 사용자가 선택한 개별 사건의 명시적 업무 비용은 별도 적용.
- 4·10월 국내학회는 직전 3·9월에 참석 계획을 정하고 실제 참석월에 비용 집행.
- 겨울 군사교육소집은 1·2월 중 3주. 그 3주 동안 연구·학습·학생 사건·직접 지도 불가. 남은 주는 복귀 후 자율 시간이며 짧은 머리 유지 기간은 훈련 기간과 분리.
- 신규 과제 선정·미선정은 실제 결과가 발생한 월말 수행보고와 결정 큐에 표시. 결과를 확인한다고 연구비를 다시 입금하지 않음.
- 교수 나이는 진행월에 따라 증가하고 나이 제한 사건·업무 여유 계산에 반영.
- wet lab의 연간 과제 규모·소모품 비용·장비 마모가 dry lab보다 큼. 초기 연구비 상한과 3책5공 제한은 공통 유지.

## 검증

새 `tests/event-branch-review.test.mjs` 8개는 자격시험 상태 5종, 언어·학위 경로·12개월 채점 시기, 이전 대기 사건 이관, 실제 희귀 상담 선택과 RNG 보존, 발생 사실과 대사의 구분, dry 모드를 제공하는 57개 전공의 양언어 장면, 수상 후속 상담, 겨울 훈련 seed 6개를 검사한다.

## 범위와 남은 한계

이 검수는 게임의 조건과 서술이 서로 맞는지 확인한다. 이벤트의 연구비 액수·준비 기간·성과 확률을 실제 대학의 보편적 기준으로 검증한 것은 아니다. 외부 연구자와 실제로 만났는지, 예정한 워크숍을 진행했는지처럼 수행 기록이 없는 일은 완료된 사실로 회상하지 않도록 메인스토리 검수에서 따로 다룬다. 전체 엔딩 분포와 성장 수치는 별도 밸런스 감사에 포함한다.
