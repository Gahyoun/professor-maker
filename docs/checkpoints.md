# 시점별 저장과 복원

연구실 기록에서 직접 저장점을 만들거나 월별 자동 저장점으로 돌아갈 수 있습니다. 자동 저장은 월 진행 직전·직후와 주요 선택 이후에 갱신됩니다. 같은 회차·같은 월의 자동 저장점은 갱신되며 직접 저장점은 덮어쓰지 않습니다.

이전 상태의 선택·파라미터·진행 중 이벤트·난수 시드를 검증하고 깊은 복사로 복원합니다. 복원 직전 상태는 별도의 자동 보관점에 저장하며, 실패하면 회귀를 중단합니다. 발견한 후일담과 CV 수집 기록은 현재 보관함을 유지합니다.

저장점은 이 브라우저의 IndexedDB에만 있습니다. 서버로 전송하지 않습니다. 최대 400개를 보관하며 한도에 도달하면 기존 저장점을 삭제하거나 파일 저장을 사용할 수 있습니다. 저장점별 파일은 기존 JSON 불러오기 형식과 호환됩니다. 전체 저장점 목록을 일반 게임 파일에 복제하지 않으므로 옮길 시점의 파일을 각각 내려받아야 합니다. 브라우저 데이터 삭제 시 파일 없이 복원할 수 없습니다. 기능 추가 이전의 월별 수치와 난수 상태는 과거 기록만으로 재구성하지 않습니다.
