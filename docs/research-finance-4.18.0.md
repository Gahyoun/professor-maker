# 4.18.0 분야별 연구비와 지출

분야별 차이는 연구비 규모와 소비 구조를 함께 조정한다. 낮은 연구비의 분야가 일방적으로 불리해지지 않도록 실제 규모 차이를 크게 압축했다. 지원사업의 실제 선정 확률이나 대학원생 한 명의 현실 비용을 재현하는 모델은 아니다.

## 공개 자료의 범위

한국연구재단 [2025 대학연구활동실태조사 분석보고서](https://www.nrf.re.kr/page/419?ac=view&boardNo=150&menuNo=419&postNo=266697)는 2024년 활동을 조사했다. 부록표 15(인쇄 쪽 147–149)의 중분류별 **전임교원 1인당 연구비**를 참고했다. 연구비 미수혜 교원도 분모에 포함하므로 개별 과제의 연간 지원액이나 수혜 교원의 평균과 다르다. 보고서의 수행률을 게임 선정 확률에 사용하지 않았다.

| 기준 분류 | 전임교원 1인당 연구비(백만원) | 신규 계약 게임 계수 |
| --- | ---: | ---: |
| 수학 | 76.48 | 0.95 |
| 컴퓨터학 | 217.9 | 1.00 |
| 물리학 | 295.73 | 1.04 |
| 건축공학 | 101.0 | 0.95 |
| 환경공학 | 265.6 | 1.03 |
| 재료공학 | 431.2 | 1.08 |
| 간호학 | 27.4 | 0.95 |

계수는 자연과학 소계 215.29백만원을 기준으로 `1 + 0.12 × ln(분야 평균 / 215.29)`를 계산한 뒤 0.95–1.15로 제한하고 소수 둘째 자리로 반올림한다. 실제 분야 간 격차는 그대로 적용하지 않는다. 직접 대응되지 않는 게임 전공은 이름이 명시된 가까운 중분류 또는 대분류를 참고하며, 별도 측정된 세부 전공 평균으로 표시하지 않는다. 전체 대응표는 `dist/research-finance.js`에 있다.

[한국연구재단의 2026년 기본연구 안내](https://webzine.nrf.re.kr/magazine/2604/sub1.php)는 지원액과 기간이 사업 유형별로 다름을 확인하는 보조 자료로 사용했다. [KISTEP 2024년도 연구개발활동조사](https://www.kistep.re.kr/reportDownload.es?rpt_no=RES0220260021&seq=res_0026P@5)의 국가 전체 비용 비율은 기업 등을 포함하므로 개별 연구실에 직접 배분하지 않았다.

## 게임 적용

- 앞으로 지급될 연구비는 기존 규칙보다 15% 늘린다. 과거 입금·잔액·이력은 수정하지 않는다.
- 신규 계약과 갱신 계약에는 분야 계수를 한 번 적용한다. 기존 계약의 미래 입금에는 공통 15% 인상만 적용한다. 계약의 저장된 계수 버전으로 중복 인상을 막는다.
- 이론·문헌, 계산·데이터, 현장·시료, 설계·모형, 생명 소모품, 장비·시편, 보건·자료 수집의 7가지 소비 구조를 둔다.
- 기본 유지비, 연구환경·성과 지원, 활동별 비용을 구분한다. 시료 조사·모형 검증·실험이 많은 달과 자료 분석·문헌 정리 달의 지출을 다르게 계획할 수 있다.
- 활동별 비용과 지원 단가는 게임 설계값이다. 공개 보고서가 해당 단가를 측정했다는 뜻은 아니다.
- 동일 단계의 인건비는 분야에 따라 차등하지 않는다. 학생인건비 풀은 운영비나 차입 상환에 쓰지 않는다.
- 정착지원은 인건비와 해당 분야의 필수 유지비 부족만 보전한다. 선택적인 환경·성과 지원과 학회 지출은 별도다.
- 월별 확정은 현금 부족으로 막지 않는다. 부족분을 자동 차입하고 원인·차입금·다음 입금·폐쇄 경고를 보여준다.

## 검증

`tests/research-finance.test.mjs`는 모든 지원 전공·연구 방식의 유한한 비용과 제한된 계수, 난수·상태 불변, 6개 대표 소비 구조, 필수 지원과 선택 지출 분리, 신규·기존 계약의 금액, 현금 0에서 월 진행과 인건비 풀 보호를 검사한다. 별도의 실제 Worker 정책 실행은 플레이어 승률이나 현실 경력 확률로 해석하지 않는다.
