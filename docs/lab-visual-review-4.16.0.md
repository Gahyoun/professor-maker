# 4.16.0 연구실 장비·계절 검수

게임 내 SVG 렌더러의 전공별 장비와 창밖을 추가했다. 연구비·능력·이벤트·플레이 RNG를 변경하지 않는 장식이다. 기존 `roomScene` API와 기본 학생 표시를 유지하고, 자체완결 SVG를 반환하는 `renderLabScene`을 추가했다.

## 전공과 연구 방식

전공 코드는 `dist/disciplines.js`의 정본을 사용했다.

| 코드 | 전공 | dry 장면 | wet 장면 |
| --- | --- | --- | --- |
| 057 | 환경학 | 계산용 모니터, 지형·유역 모형과 관측 지도 | 토양·수질 시료 분석기, 층위가 보이는 토양 코어, 수질 측정기·전극, 시료 트레이 |
| 077 | 환경공학 | 환경학과 같은 분석·지도 장비 | 환경학과 같은 토양·수질 분석 장비 |
| 072 | 건축학 | 층별 축척 모형과 건축 도면 | 전공 설정상 dry만 지원 |
| 073 | 건축공학 | 층별 축척 모형과 건축 도면 | 하중 재하 프레임, 하중·변형률 계측기, 콘크리트 시험체 |
| 075 | 토목공학 | 교량 상부구조·교각 축척 모형 | 하중 재하 프레임, 하중·변형률 계측기, 토양 코어 시료 |

장비는 기존 책상·바닥과 같은 투영 함수를 사용한다. 실험 장비는 랩 테이블의 상판에 두고, dry 장면에는 wet 분석기를 넣지 않았다. 기존 일반 전공의 생물/분석/계측/설계/전산 구분도 유지했다.

## 계절과 졸업 기록

국문은 1년차 3월, 영문은 1년차 9월을 기준으로 한다. 봄은 3–5월(연녹색·꽃), 여름은 6–8월(녹색 수관), 가을은 9–11월(황갈색·낙엽), 겨울은 12–2월(앙상한 가지·눈)이다. 창문은 기존 벽면 원근에 맞춰 투영한다.

대기 장면은 현재 표시월을, 주간 실행 장면은 마지막 수행월을 사용한다. 명시적인 `visualMonth`가 있으면 우선한다. 종료 `month=96`은 마지막 유효월 95에 고정해 국문 2월/영문 8월을 유지한다. CV에서 마지막 수행월을 명시하면 그 풍경을 그대로 보관할 수 있다.

`renderLabScene(..., {idle:true, student:false})`는 학생 도트만 생략하고 의자·실내·장비·창밖을 보존한다. 기본은 학생 표시이며, 자재량은 실제 `supplyLevel(state)`를 따른다. 외부 이미지·스크립트·스타일 없이 단독 SVG 이미지로 디코딩된다. 최종 CV 압축·보관 용량 검수는 CV 담당 모듈에서 수행한다.

## 확인 결과

- 단위 테스트 16개 통과: 전공 73개 결정적 렌더와 상태/RNG 불변, 국·영문 달력 및 95/96 경계, 자재 3단계, SVG 자체완결성을 확인했다.
- 기존 3.5등신 학생과 안전 헤어는 수정하지 않았다. 의자 지지대·5개 바퀴·팔걸이, 의자 뒤쪽 → 학생 → 의자 앞쪽 → 책상 앞쪽의 레이어 회귀가 통과했다.
- 별도 headless Chromium에서 5개 전공의 지원 모드 9조합 × 4계절 = 36개 장면을 320px/1360px에서 검증했다(72개 배치). 장비·창문이 화면 밖으로 벗어나지 않고 가로 넘침·브라우저 오류가 없었다. CSS 없는 CV형 SVG 이미지도 디코딩됐다.
- 환경학/건축공학/토목공학의 dry·wet 네 계절 비교와 작업 장면 비교 이미지를 직접 검수했다. 꽃/수관/낙엽/눈, 모형/분석기/시료, 좌석·책상 원근과 장비 받침을 확인했다.
- `engine.js`, `workload.js`, `balance.js`, `relationship.js`, `funding.js`, `grants.js`는 최종 밸런스 감사의 해시와 같다. 기존 감사 자료와 수치를 변경하지 않았다.
